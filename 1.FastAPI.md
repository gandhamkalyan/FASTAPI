> FastAPI is a Python framework used to build APIs very quickly.



Think of it like this:



**Frontend / User / App**

&#x20;       **↓**

&#x20;   **FastAPI Server**

&#x20;       **↓**

&#x20;**Database / AI Model / Files / Services**



> FastAPI acts like a waiter in a restaurant.



Example:

User asks:

"Give me customer details"

FastAPI receives request

FastAPI talks to database

FastAPI sends response back

\-------------------------------------

What is an API?



API = Application Programming Interface

Simple meaning: A way for two software systems to communicate.

**What is a Route?**



Route = API endpoint.



Example:

| Route       | Purpose      |

| ----------- | ------------ |

| `/users`    | Get users    |

| `/products` | Get products |

| `/orders`   | Get orders   |

\----------------------------------------------------

**HTTP Methods**



These are VERY IMPORTANT.



| Method | Meaning             |

| ------ | ------------------- |

| GET    | Read data           |

| POST   | Create data         |

| PUT    | Update entire data  |

| PATCH  | Update partial data |

| DELETE | Delete data         |
