**Path Parameters**



\- A path parameter is a value passed inside the URL path.



Example URL: /products/101

Here: 101 is the path parameter.





2\. Real-World Analogy



Think about Amazon product pages.

Example: amazon.com/product/12345



The product ID changes for every product.



12345 is the path parameter.



FastAPI captures this value dynamically.



3\. Why We Need Path Parameters



Without path parameters:

/product1

/product2

/product3

This is bad.



Instead: /products/{product\_id}

Dynamic and scalable.

**Query Parameter**



A query parameter is data sent in the URL after ?.



Example: /products?category=laptop

Here: category=laptop is the query parameter.



2\. Structure of Query Parameters



General format: URL?key=value

Example: /search?name=Rahul



Where:

name → parameter name

Rahul → value



**Difference Between Path and Query Parameters**



PATH PARAMETER : Used to identify a specific resource.



Example: /products/101

Here: 101 = specific product

Think: "WHICH resource?"



> QUERY PARAMETER : Used to filter/search/customize results.



Example: /products?category=laptop

Think: "HOW should data be filtered?"
